# Stytch LLM Agent Starter

Starter code for building a B2B LLM application with Stytch authentication and LangChain.

This is the baseline for the tutorial **"Building a B2B LLM chatbot with Stytch and LangChain"**.

## Quick Start

```bash
git clone https://github.com/jonathansandman/langchain-stytch-agent-starter.git
cd langchain-stytch-agent-starter
git checkout wod-start-here
```

For complete setup and implementation instructions, see the tutorial article: **"Building a B2B LLM chatbot with Stytch and LangChain"**.

## What's Included

- **Frontend**: React + Vite application (scaffolded)
- **Backend**: FastAPI + Python (scaffolded)
- **Connected App**: CLI tool for OAuth integration (scaffolded)

This starter provides the basic structure. The tutorial walks you through adding authentication, RBAC, LLM integration, caching, and Connected Apps.
